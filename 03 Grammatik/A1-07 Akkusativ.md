# Akkusativ

> [!abstract] Ne öğreneceksin
> Belirtme hâli: der → den, ein → einen; haben, sehen, kaufen gibi fiillerle.

**Ön koşullar:** [[A1-04 Artikel und Genus]]

## Ders notu
Akkusativ cümlenin **nesnesidir**: "neyi, kimi?" sorusunun cevabı. Fiillerin çoğu (*haben, kaufen, sehen, trinken, essen, brauchen, es gibt*) bir Akkusativ nesnesi ister.

İyi haber: Akkusativ'de **sadece eril (der) isimler değişir**. Dişil, nötr ve çoğul olduğu gibi kalır.

| | Nominativ (özne) | Akkusativ (nesne) |
|---|---|---|
| **eril** | der / ein / kein / mein | **den / einen / keinen / meinen** |
| dişil | die / eine | die / eine |
| nötr | das / ein | das / ein |
| çoğul | die / – | die / – |

- Ich habe **einen** Bruder. → Bir erkek kardeşim var.
- Wir kaufen **den** Tisch. → Masayı satın alıyoruz.
- Sie trinkt **einen** Kaffee. → Bir kahve içiyor.
- Ich sehe **die** Frau. → Kadını görüyorum. *(dişil, değişmez)*
- Er braucht **ein** Messer. → Bir bıçağa ihtiyacı var. *(nötr, değişmez)*

> [!warning] Türklerin sık yaptığı hata
> Türkçede belirtme eki ismin sonuna gelir: masa**yı**. Almancada isim değil **artikel** değişir: der Tisch → **den** Tisch. *Es gibt* de Akkusativ ister: Es gibt **einen** Park.
