# 🃏 Kartlar

Antrenman olmayan günlerde de buradan çalışabilirsin: hatırlatmalar bugünün tarihiyle gelir. Antrenman notundaki kartlarla aynı destedir; bir yerde kaydırdığın kart diğerinde de kaydırılmış görünür.

Kartı çevirmek için üstüne dokun. Biliyorsan **sağa**, bilmiyorsan **sola** at (ya da ✓ / ✗ düğmeleri, klavyede ← →).

```dataviewjs
await dv.view("_sistem/kartlar", { deste: "kelime", adet: 10 })
```

```dataviewjs
await dv.view("_sistem/kartlar", { deste: "cumle", adet: 10 })
```
